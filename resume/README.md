# Personal portfolio

The homepage uses a sticky profile sidebar beside a naturally scrolling main column. Its section index links to experience, featured projects, additional research, publications and recognition, and skills. Project cards link to dedicated pages under `projects/`, with spaces for fuller descriptions, diagrams, experiments, demos, and code links.

## Preview

Open `index.html` in a browser. The site is static HTML and CSS and needs no build step.
