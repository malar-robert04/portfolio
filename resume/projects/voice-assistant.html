INDEPENDENT TECHNICAL PROJECT · MULTILINGUAL AI

AI-Powered Filipino–Korean Voice Assistant

Developing a multilingual conversational voice assistant integrating speech recognition, local LLM inference, translation, information retrieval, and speech synthesis for telephone-based communication.

Python Faster-Whisper Ollama Qwen3 Edge TTS Speech Processing LLM Integration

1. Project Overview

This project explores the development of an AI-powered multilingual telephone assistant designed to facilitate communication between Filipino-speaking callers and Korean-speaking recipients.

The primary objective is to reduce language barriers in everyday telephone conversations by integrating automatic speech recognition, language understanding, machine translation, response generation, and text-to-speech into a unified conversational pipeline.

Rather than translating isolated sentences, the system is designed to understand incoming messages, identify the caller's intent, generate contextually appropriate responses, and communicate those responses through synthesized speech.

The project is being developed in two stages: first establishing the AI processing pipeline, followed by integration with a telephone communication system for real-time call handling.

2. Problem Definition and Motivation

Language differences can make everyday telephone communication difficult, particularly when Filipino-speaking individuals need to communicate with Korean-speaking contacts.

Existing communication approaches often depend on human interpreters or manual translation applications. These methods can interrupt natural conversations, require additional effort, and may not be practical when immediate responses are needed.

This project investigates whether an AI-based voice assistant can provide a more continuous conversational experience by automatically processing speech, understanding the message, translating information, and generating spoken responses in the required language.

3. System Architecture

The proposed architecture consists of two major layers: an AI processing layer responsible for understanding and generating conversational responses, and a telephone communication layer responsible for handling incoming and outgoing audio streams.

Layer 1 – AI Processing Pipeline

The AI processing layer handles the transformation of incoming speech into meaningful conversational responses.

  1. Speech Recognition: Faster-Whisper converts recorded speech into text and supports language identification.
  2. Language Processing: The recognized text is processed to determine the language and the nature of the request.
  3. Intent Classification: An intent-processing module identifies whether the message requires translation, a conversational response, or information retrieval.
  4. LLM-Based Understanding and Response Generation: Ollama with the Qwen3 model is used for language understanding, translation, and contextual response generation.
  5. Information Retrieval: Additional integrations with Open-Meteo and web search support weather-related and factual queries.
  6. Speech Synthesis: Edge TTS converts the generated text into spoken audio for the intended recipient.

Layer 2 – Telephone Communication

The second layer is designed to connect the AI processing pipeline with a telephone network.

  • Existing LG U+ mobile number as the intended telephone entry point.
  • Investigation of call forwarding and compatible SIP/070 connectivity options.
  • Asterisk PBX for telephone call management.
  • Python-based integration for bidirectional audio processing between the telephone system and AI pipeline.

This layer is currently under development. The objective is to establish a reliable audio connection that allows incoming speech to be processed by the AI system and generated responses to be returned to the caller.

4. Speech Processing and Multilingual Conversation

The core processing pipeline is designed around the conversion of spoken language into text, contextual interpretation, and the generation of spoken responses.

Speech-to-Text

Faster-Whisper is used to transcribe recorded Filipino and Korean speech into text. Language identification helps determine the appropriate processing path for the recognized message.

Language Understanding and Translation

The recognized text is passed to a locally hosted Qwen3 model through Ollama. The model is used for translation, understanding the caller's message, and generating contextually appropriate responses.

An intent-classification component helps distinguish translation requests from conversational and information-seeking requests, allowing the system to follow different response paths.

Text-to-Speech

Edge TTS is integrated to convert generated responses into spoken audio. This enables the processing pipeline to produce audio output rather than relying solely on translated text.

The current development focuses on making the transcription, language processing, and speech generation components work together as a unified pipeline.

5. Contextual Responses and Information Retrieval

Beyond direct translation, the system is being extended to support information-based interactions. The objective is to allow the assistant to process requests that require information retrieval rather than simply converting speech from one language to another.

  • Weather Information: Open-Meteo integration supports weather-related queries.
  • Web-Based Information: Search integration supports retrieving information for factual queries.
  • LLM Response Generation: Retrieved information can be incorporated into generated responses.

These capabilities extend the system from a basic translation pipeline towards a more flexible conversational assistant.

6. Implementation and Development Progress

Development began with establishing the AI processing pipeline independently of the telephone network. Recorded audio files were used to test individual components and validate the flow of information between them.

Implemented and Tested

  • Speech transcription using Faster-Whisper.
  • Filipino and Korean language processing.
  • Local LLM integration using Ollama and Qwen3.
  • Translation and conversational response generation.
  • Intent classification for different request types.
  • Speech generation using Edge TTS.
  • Weather and web-based information retrieval integrations.

Current Development Priorities

  • Improving response latency and overall processing speed.
  • Developing continuous audio input and output handling.
  • Integrating bidirectional audio communication with the telephone system.
  • Establishing call management through Asterisk PBX and a compatible telephony connection.
  • Developing a monitoring dashboard for call sessions, transcriptions, translations, response times, and system status.

7. Monitoring and System Management

A web-based monitoring dashboard is planned as part of the overall system. It will provide visibility into the assistant's operation and help evaluate the performance of individual processing stages.

The planned monitoring features include call-session information, speech transcription, translated messages, generated responses, processing time, and system status.

The dashboard will support debugging and performance analysis as the AI pipeline is integrated with the telephone communication layer.

8. Evaluation and Future Testing

The current validation focuses on recorded-audio testing of the AI processing pipeline. The next evaluation stage will involve controlled telephone conversations after the telephony integration has been completed.

The planned evaluation criteria include:

  • Speech recognition accuracy across Filipino and Korean.
  • Translation quality and preservation of conversational meaning.
  • Intent classification and response relevance.
  • End-to-end response latency.
  • Speech synthesis quality and intelligibility.
  • Reliability of bidirectional telephone audio communication.

These evaluations will help identify bottlenecks and guide further improvements to the system.

9. Future Direction and Expected Impact

The longer-term goal is to develop an accessible multilingual telephone assistant capable of handling natural conversations across language barriers.

Once telephone integration is established, future improvements will focus on reducing response latency, supporting more natural conversational turn-taking, improving contextual understanding, and extending language support.

The broader vision is to explore how locally hosted language models and speech-processing technologies can be combined to create practical AI communication systems for everyday and workplace interactions.
